\chapter*{АНОТАЦІЯ}
\addcontentsline{toc}{chapter}{АНОТАЦІЯ}

У роботі досліджено метод трасування променів у дискретному воксельному просторі на основі загального світового воксельного об'єму для графічного рендерингу в реальному часі. Розглянуто основні поняття воксельного представлення 3D сцен, методи оптимізації трасування променів та їх застосування для інтерактивних графічних застосунків.

Проаналізовано структури даних для зберігання воксельних об'ємів на GPU, включаючи 3D текстури з MIP-рівнями як спрощений аналог октодерева. Досліджено алгоритм швидкого проходження воксельного простору Amanatides \& Woo та його адаптацію для ієрархічного трасування. Визначено переваги використання загального воксельного об'єму порівняно з лінійними BVH структурами для воксельних сцен.

Розроблено модульну архітектуру системи трасування на базі ігрового рушія Bevy (Rust) та шейдерної мови WGSL. Реалізовано повний пайплайн відкладеного рендерингу з двома проходами: геометричним (заповнення G-буфера з глибиною та нормалями) та світловим (обчислення м'яких тіней та ambient occlusion). Впроваджено інверсивне мапування для коректної вокселізації орієнтованих об'єктів у світовий об'єм з використанням інверсних матриць трансформації.

Розроблений прототип демонструє життєздатність підходу для інтерактивних застосунків. Система забезпечує баланс між якістю зображення та продуктивністю, що робить її придатною для ігрових рушіїв з воксельною естетикою, систем візуалізації та освітніх програм. Модульна архітектура на базі Bevy ECS та використання Rust забезпечують підтримуваність коду та можливість подальшого розширення.
